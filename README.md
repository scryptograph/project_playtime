# Project Playtime

**Project Playtime** is an open-source, interactive platform designed to empower non-verbal children with special needs by enhancing their communication abilities. Built with **Ionic** and **Angular**, this app integrates cross-platform functionality with native capabilities to create a seamless experience. The project combines modern web technologies to provide an accessible and intuitive tool that promotes inclusivity and fosters meaningful interactions for children who face communication challenges.

## Features
- Developed with **Ionic Framework** for a responsive, cross-platform user experience.
- Integrates **Capacitor** for native functionalities.
- Built using **TypeScript**, **HTML**, **CSS**, and **JavaScript**.

## Getting Started

### Prerequisites
- Node.js
- Ionic CLI
- Capacitor

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/scryptograph/project_playtime.git
   ```
2. Install Dependencies:
   ```bash
   npm install
   ```
### Run the App
To run the app in a development server
```bash
ionic serve
```
